# 💬 Chat Application With Java

**Ghosty** is a real-time chat application that lets you join trending chatrooms, connect with others, and share your thoughts instantly all in a simple and modern interface.

## Features
Ghosty offers a wide range of features designed to enhance your chatting experience. You can switch between dark and light themes, enable or disable notification sounds, and choose from four different language options. 
Users can customize their profiles by changing their profile pictures, create new chatrooms, and join rooms created by others to engage in real-time conversations.
